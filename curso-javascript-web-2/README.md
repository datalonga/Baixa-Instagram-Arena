# Curso visual moderno de JavaScript — etapa de amostra

Esta pasta contém o **prompt mestre** e uma aula de demonstração para aprovação. Conforme solicitado, o curso completo e sua estrutura de módulos ainda não foram produzidos.

## Aula de exemplo

- [Assistir ao MP4 da aula de demonstração](amostra/aula-exemplo.mp4)
- [Baixar o pacote da amostra](amostra/pacote-amostra.zip)
- [Ler o roteiro falado/legendado](amostra/roteiro.md)
- [Ver as legendas SRT](amostra/legendas.srt)

A demonstração apresenta a criação simulada dos arquivos `index.html` e `app.js`, digitação animada do código, prévia ao vivo no navegador e narração em português brasileiro. Cada frase falada aparece como legenda com o mesmo texto. O áudio usa a voz masculina selecionada anteriormente.

## Prompt mestre

A especificação completa de tom pedagógico, visual, sincronização fala-legenda, motion design, animação de código, estrutura e verificações está em [`PROMPT_MESTRE.md`](PROMPT_MESTRE.md).

## Aprovação

Depois que você aprovar a amostra ou pedir ajustes, podemos congelar esse padrão e então criar a estrutura integral do curso do básico ao avançado. Nenhum módulo completo foi iniciado nesta pasta além desta aula-modelo.
