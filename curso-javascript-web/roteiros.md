# Roteiros das aulas 1 a 3

## Aula 1 — Seu ambiente e a primeira página

### Parte 1 — O mapa da web
Bem-vindo ao curso de JavaScript para a web. Vamos começar entendendo o que acontece quando você abre uma página. O HTML descreve o conteúdo, como títulos, parágrafos, campos e botões. O CSS cuida da aparência: cores, espaçamento e organização. O JavaScript acrescenta comportamento. Ele pode responder a um clique, validar um formulário ou buscar informações pela internet. Pense nessas três tecnologias como partes que trabalham juntas, não como concorrentes. Nesta aula vamos preparar um projeto pequeno, abrir o console do navegador e executar nossas primeiras instruções. Crie uma pasta chamada meu-primeiro-projeto. Dentro dela, crie dois arquivos: index ponto html e app ponto js. O primeiro será a página; o segundo conterá nosso código. Não precisamos instalar um editor especial nem configurar um servidor para os primeiros exemplos. Um editor de texto e um navegador moderno já são suficientes. Mais adiante vamos organizar o projeto melhor, mas agora o objetivo é ver cada linha funcionando e aprender a observar o que o navegador está fazendo.

### Parte 2 — Conectando os arquivos
Vamos ligar os dois arquivos. No index ponto html, escreva a estrutura básica de uma página: a declaração do documento, as tags html, head e body. Dentro do head, coloque um título para a aba do navegador. No body, adicione um título visível para a página. Antes de fechar o body, inclua uma tag script com o atributo defer e o caminho app ponto js. O atributo defer manda o navegador carregar o arquivo sem interromper a leitura do HTML e executá-lo quando a página estiver pronta. Agora abra o arquivo no navegador. Clique com o botão direito, escolha inspecionar e encontre a aba Console. Ferramentas do desenvolvedor variam um pouco entre navegadores, mas o console existe em todos os principais. No arquivo app ponto js, escreva console ponto log, abra parênteses, coloque entre aspas a frase Olá, JavaScript, e feche os parênteses. Salve, volte ao navegador e atualize a página. A mensagem aparece no console. Você acabou de executar JavaScript de verdade. Se não aparecer, confira se os nomes dos arquivos estão corretos, se a tag script aponta para app ponto js e se salvou as alterações.

### Parte 3 — O console e os erros
O console será nosso laboratório durante o curso. Ele mostra mensagens, resultados e erros que ajudam a investigar o programa. Troque a mensagem por duas instruções: uma que mostre o nome da sua página e outra que mostre uma conta simples, como oito mais quatro. Salve e atualize. Cada linha executa uma instrução; o ponto e vírgula no fim é opcional em muitos casos, mas vamos usá-lo de forma consistente nos exemplos. Quando aparecer uma mensagem vermelha, não entre em pânico. Leia o texto com calma, procure o nome do arquivo e o número da linha. Um erro de sintaxe costuma significar que faltou uma aspa, um parêntese ou uma chave. Agora pratique: altere o texto, faça uma multiplicação e provoque intencionalmente um erro removendo uma aspa; observe o que o navegador informa e corrija. Ao terminar, você deve conseguir abrir um arquivo HTML, carregar um arquivo JavaScript e usar o console para testar instruções. Essa rotina de observar, mudar e testar será útil em todas as próximas aulas. Na próxima, vamos guardar valores em variáveis e trabalhar com os tipos de dados fundamentais.

## Aula 2 — Variáveis, tipos e operadores

### Parte 1 — Variáveis
Nesta aula vamos aprender a guardar informações em variáveis. Uma variável tem um nome e aponta para um valor que o programa pode consultar. Em JavaScript moderno, normalmente começamos com const. Por exemplo: const curso é igual a JavaScript. Lemos essa linha como criar uma constante chamada curso com o texto JavaScript. Use const quando não pretende atribuir outro valor à variável. Se precisar atualizar o valor, use let. Um contador de pontos pode começar em zero e receber mais pontos durante o jogo. Escreva let pontos é igual a zero; depois, pontos recebe pontos mais cinco. O operador mais igual a cinco faz a mesma atualização de forma curta. Escolha o nome com cuidado. Nomes como total de pedidos ou nome do usuário comunicam a intenção melhor do que x ou dado. Em JavaScript, nomes de variáveis normalmente usam camel case: a primeira palavra começa com minúscula e as seguintes começam com maiúscula. Não inclua espaços no nome. Use uma letra, cifrão ou sublinhado no início, e evite palavras reservadas da linguagem. Também é comum escrever constantes que representam configurações fixas em letras maiúsculas, mas para a maioria dos valores basta um nome normal e claro.

### Parte 2 — Tipos e strings
Agora vamos reconhecer os tipos de valores. Uma string é texto, como JavaScript entre aspas. Um number representa número inteiro ou decimal. Um boolean tem somente dois valores: true ou false, verdadeiro ou falso. Esses valores são úteis para decisões. Também encontramos null, que representa uma ausência escolhida explicitamente, e undefined, que normalmente indica que um valor ainda não foi definido. Teste no console typeof JavaScript, typeof vinte e dois e typeof true. A palavra typeof ajuda a investigar o tipo durante o desenvolvimento. Para juntar texto e valores, use uma template string, escrita com crases. Dentro dela, cifrão e chaves inserem o resultado de uma expressão. Por exemplo, defina uma variável nome como Lia e crie a frase Olá, nome, usando cifrão e chaves ao redor da variável. O resultado será Olá, Lia. Isso fica mais legível do que concatenar vários pedaços de texto com sinais de mais. Um detalhe importante: valores de tipos diferentes podem se comportar de formas inesperadas quando misturados. O sinal de mais pode somar dois números ou juntar texto. Por isso, confira o tipo e converta os dados quando necessário, em vez de confiar em coerções automáticas.

### Parte 3 — Operadores
Vamos combinar variáveis com operadores. Mais, menos, vezes e dividido fazem operações aritméticas. Os operadores menor que, maior que e maior ou igual comparam valores e devolvem um booleano. Para verificar igualdade, prefira três sinais de igual. A igualdade estrita compara tanto o valor quanto o tipo: cinco número não é igual a cinco texto. Dois sinais de igual podem converter um tipo automaticamente e produzir surpresas. O sinal de exclamação com dois iguais verifica diferença estrita. Para combinar condições, use dois e comerciais, que significam e, ou duas barras verticais, que significam ou. Uma condição com e só é verdadeira se as duas partes forem verdadeiras. Com ou, basta uma parte verdadeira. Experimente definir idade como dezessete e tem autorização como verdadeiro. Compare idade maior ou igual a dezoito, depois combine essa condição com autorização usando e. Leia o resultado no console. Um modelo mental útil é separar dado, operação e resultado: guarde os valores com nomes, aplique o operador e observe o booleano ou número produzido. Na próxima aula, vamos usar esses booleanos para escolher caminhos com if e else, e depois repetir tarefas com laços.

## Aula 3 — Decisões e laços de repetição

### Parte 1 — Condicionais
Uma condição permite que o programa siga caminhos diferentes. A estrutura if recebe uma expressão entre parênteses. Se o resultado for true, o bloco entre chaves executa. Considere uma variável idade com valor vinte. Se idade for maior ou igual a dezoito, mostramos a mensagem Pode entrar. Caso contrário, o bloco else mostra Acesso não permitido. O else é opcional, mas útil quando precisamos cobrir os dois resultados. Leia a regra em voz alta antes de programar. Isso ajuda a descobrir se você quer maior que ou maior ou igual a. Agora acrescente uma regra de classificação: se a nota for pelo menos noventa, resultado A; se for pelo menos setenta, resultado B; em qualquer outro caso, resultado C. Use else if para as alternativas intermediárias. A ordem importa: verifique primeiro o limite maior. Se a nota for noventa e cinco e você começar perguntando se é pelo menos setenta, o programa já entrará nesse bloco e não chegará ao A. Teste valores exatamente no limite e um ponto abaixo. Esse hábito de testar casos de fronteira evita bugs em idades mínimas, descontos, notas e formulários.

### Parte 2 — Operadores lógicos
Operadores lógicos ajudam a combinar regras reais. Dois e comerciais significam e: as duas condições precisam ser verdadeiras. Duas barras verticais significam ou: basta uma condição verdadeira. O sinal de exclamação inverte um booleano. Imagine uma promoção disponível para clientes cadastrados que gastaram pelo menos cem reais. A regra é cadastrado e total maior ou igual a cem. Se qualquer parte for falsa, a promoção não se aplica. Agora imagine uma área liberada para administradores ou para quem tem convite; aqui usamos ou. Coloque cada comparação entre parênteses quando isso deixar a expressão mais fácil de ler. Se a condição ficar longa, guarde partes em variáveis com nomes como temConvite ou compraElegivel. Nomes bons fazem a regra quase se explicar sozinha. Evite repetir a mesma condição em vários lugares; uma função pequena pode concentrar a regra e facilitar a manutenção. Faça testes cobrindo os resultados possíveis: ambos verdadeiros, ambos falsos e apenas um verdadeiro. Essa tabela mental ajuda especialmente quando combinamos e com ou. JavaScript avalia os operadores em uma ordem definida, mas parênteses tornam a intenção clara para quem lê, inclusive você no futuro.

### Parte 3 — Laços
Laços repetem instruções. O for é ótimo quando sabemos quantas vezes queremos repetir. Ele tem três partes: inicialização do contador, condição para continuar e atualização do contador. Comece com let indice igual a zero; continue enquanto indice for menor que três; some um ao final de cada volta. O console mostra zero, um e dois. Repare que o limite três não aparece, porque a condição usa menor que. Para percorrer os valores de uma lista, for of costuma ficar mais claro. Primeiro crie um array de cores, depois escreva for const cor of cores, abra chaves e mostre cor no console. Cada volta recebe o próximo valor. Atenção aos laços infinitos: a condição precisa eventualmente ficar falsa. Se o contador não for atualizado, o programa pode continuar sem parar. Pratique escrevendo um laço que mostra os números de um a cinco e outro que percorre uma lista de nomes. Nesta aula vimos escolhas, condições e repetição. Desafio: escreva uma regra que classifica uma nota e percorra uma lista de notas para mostrar cada resultado. Nas próximas aulas vamos organizar lógica em funções e trabalhar com coleções maiores de dados.
