# Textos da narração

## Aula 1 — Variáveis
Comece escolhendo como guardar seus dados. Use const quando a variável não será reatribuída; é o padrão mais seguro. Quando o valor precisa mudar, como num contador, escolha let. Defina pontos com zero e depois some cinco. Para exibir o resultado, use console ponto log. Prefira nomes claros e teste cada linha no console. Agora, crie uma variável com sua meta de estudo.

## Aula 2 — Tipos de dados
Todo valor em JavaScript tem um tipo. Texto entre aspas é string. Números servem para fazer contas, e booleanos representam verdadeiro ou falso. Use crases para criar uma mensagem com variáveis: olá, vírgula, nome. Também existem null, uma ausência definida de propósito, e undefined, quando ainda não há valor atribuído. Experimente typeof no console e descubra o tipo de cada exemplo.

## Aula 3 — Decisões
Com if, seu programa pode tomar decisões. Coloque a condição entre parênteses e o código dentro das chaves. Prefira comparar com três sinais de igual, que verificam valor e tipo. Use else para definir o que acontece quando a condição é falsa. Para combinar regras, use e comercial e ou barras verticais. Teste também os valores no limite da condição.

## Aula 4 — Laços
Laços repetem tarefas sem copiar e colar código. No for, você inicializa um contador, verifica uma condição e atualiza o contador a cada volta. Use for of quando quiser percorrer os valores de uma lista. Em um while, confira se a condição muda dentro do bloco; caso contrário, o laço pode nunca terminar. Conte de zero até dois e observe a saída.

## Aula 5 — Funções
Uma função agrupa uma tarefa reutilizável. Ela pode receber parâmetros, processar os dados e devolver um resultado com return. Por exemplo, uma função somar recebe dois valores e retorna a soma. A sintaxe arrow usa o sinal maior que depois do igual. Para uma expressão simples, você pode omitir as chaves e o return. Crie funções pequenas, com nomes que expliquem sua intenção.

## Aula 6 — Arrays
Arrays guardam listas de valores. O método map transforma cada item e devolve uma nova lista do mesmo tamanho. Já filter seleciona os itens que passam por uma condição, então o resultado pode ser menor. Você pode encadear os dois: primeiro transformar os valores, depois filtrar. Experimente dobrar uma lista de números e manter apenas os resultados maiores que dez.

## Aula 7 — Objetos
Objetos agrupam dados relacionados em pares de chave e valor. Acesse uma propriedade com ponto, como pessoa ponto nome, ou use colchetes quando a chave estiver numa variável. A desestruturação extrai propriedades de forma direta: entre chaves, escreva os nomes que precisa. O operador spread ajuda a criar uma cópia rasa com alterações. Use objetos para representar pessoas, produtos ou qualquer entidade do seu projeto.

## Aula 8 — DOM e eventos
O DOM conecta seu JavaScript à página. Use document ponto query selector com um seletor CSS para encontrar um elemento. Depois, add event listener permite responder a cliques, digitação e outros eventos. Por exemplo, ao clicar num botão, atualize o texto da página com text content. Confira se o elemento foi encontrado antes de usá-lo, e prefira text content a inserir HTML de usuários.

## Aula 9 — Async e fetch
Fetch faz uma requisição e retorna uma promessa, porque a rede leva tempo. Dentro de uma função async, use await para esperar a resposta sem bloquear a página. Depois, converta os dados com resposta ponto json, que também é assíncrono. Envolva o processo com try e catch para tratar falhas. E lembre-se: verifique resposta ponto ok; um erro quatrocentos e quatro não rejeita a promessa automaticamente.

## Aula 10 — Módulos e projeto
Módulos ajudam a organizar o projeto em arquivos reutilizáveis. Exporte funções com export e importe pelo caminho do arquivo. No navegador, use type module na tag script para habilitar essa sintaxe. Agora, junte tudo num contador: uma variável guarda o total, o DOM encontra o botão, e um evento de clique incrementa o valor na tela. Você já conhece a base. Escolha uma ideia pequena e comece a construir.
